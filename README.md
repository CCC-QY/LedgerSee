# LedgerSee 智能记账

[![Latest Release](https://img.shields.io/github/v/release/CCC-QY/LedgerSee?label=release)](https://github.com/CCC-QY/LedgerSee/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Android%208.0%2B-green.svg)](https://github.com/CCC-QY/LedgerSee)

一款 Android 本地智能记账应用：监听支付类通知自动入账，也支持手动记账、截图记账、预算、统计与数据备份。  
当前版本：**v1.2.0**

> 本项目基于 [SmartLedger](https://github.com/huanghhcri/SmartLedger) 二次开发，遵循 MIT 协议。上游署名见 [NOTICE](NOTICE)。

## ✨ 功能特点

### 🤖 自动记账

- **多渠道监听**：微信、支付宝、云闪付、抖音、京东 / 淘宝收银台，以及工农中建招等主流银行 App
- **双向识别**：支出（消费、转账）与收入（退款、红包、转入）
- **聚合通知补全**：系统折叠成「[N条]」摘要时，从同组子通知补全金额（付款码、银行动账等）
- **防误记**：过滤企业号营销、电商促销等「见元就记」的噪声文案
- **模糊确认**：金额不完整或置信度不足时弹窗确认，可修改金额后再入账
- **智能去重**：跨渠道同笔交易合并，避免微信 + 银行双通知记两笔
- **智能分类**：按商户名匹配餐饮 / 交通 / 购物等分类，可事后修改
- **监听保活**：权限失效、服务假断开时在 App 内提示并引导恢复

### 🧠 AI 财务复盘（可选）

- 基于本月 / 历史账单生成月度复盘
- 支持「专业型」与「聊天型」两种语气
- 先在本机汇总统计，再由 DeepSeek 生成解释与建议
- API Key 使用 Android Keystore 加密保存在本机
- 只发送聚合统计；不发送通知原文、短信、卡号或备注

### 📷 截图记账

- 从相册选择微信 / 支付宝 / 银行账单截图
- 本地中文 OCR 识别，截图不上传
- 自动提取金额、商户、收/支、渠道与时间
- 识别后可修改分类、金额、商户，再保存

### 💬 碎碎念（可选）

- 一天最多一条，偶尔就某笔账单说一句话，不做账目提醒
- 本机打分挑素材：深夜下单、明显偏离同类日常、短期反复光顾、特殊金额、久未出现的分类
- **没有值得说的就不说**；网络失败、未配 Key 或内容被过滤时使用内置台词
- 点击通知可直达那一笔账单，也可以直接回它一句
- 开启后会把该笔的金额、分类、商户发送给 DeepSeek；关闭则全部留在本机

### 🗣 和碎碎聊聊（可选）

- 同一个角色，从「它说」变成「你问」：这个月花了多少、哪笔最离谱、最近都在吃什么
- 每轮会把你最近的账单摘要（本月收支、分类占比、最近十笔）发给 DeepSeek，**备注与通知原文不发送**
- 对话存在本机数据库，可随时清空；清空只删聊天记录，不影响账单
- 未配置 API Key 时不假装能聊，直接给配置入口

### ✍️ 手动记账

- 支出 / 收入切换、数字键盘、分类网格
- **渠道可选**：微信、支付宝、云闪付、现金、银行卡、抖音、京东，或自定义
- 编辑账单时可改金额、商户、备注、**渠道**、分类，以及**支出/收入方向**（切换后分类自动换成对应方向）

### 📊 首页与统计

- **总余额**：期初 + 全部收入 − 全部支出，可点按设置期初
- 今日支出、本月收支；支持切换历史月份
- 日 / 周 / 月 / 年统计、分类占比、排行与趋势
- 搜索：按关键词、收支类型、渠道、分类筛选

### 💰 预算管理

- 月度总预算、分类预算
- 使用进度展示

### 🎨 外观与个人

- 浅色 / 深色 / 跟随系统
- 自定义昵称、陪伴天数
- 设置内反馈建议入口

### 🔄 更新与数据

- **应用内检查更新**：启动自动检测 + 设置页手动检测
- **断点续传**：更新包下载失败可从上次进度继续
- CSV 导出；本地备份 / 恢复（含重装后发现历史备份）
- 分类管理（增删改）

## 🚀 安装方式

### 自行编译

```bash
git clone https://github.com/CCC-QY/LedgerSee.git
cd LedgerSee
```

用 Android Studio 打开工程，连接真机或模拟器后 Run。  
Release 签名从 `local.properties` 读取（勿提交密钥到仓库）。

## 📋 系统要求

- Android 8.0（API 26）及以上
- 建议 Android 10+，国产机请额外开启自启动 / 关闭电池优化以保证监听稳定

## 🔐 权限说明

| 权限 | 用途 | 是否必须 |
|------|------|----------|
| 通知监听 | 读取支付通知并自动记账 | ✅ 核心 |
| 悬浮窗 | 不确定账单的确认弹窗 | 推荐 |
| 安装未知应用 | 应用内下载更新后安装 APK | 更新时需要 |
| 存储 / 文件访问 | 导出 CSV、备份恢复 | 按需 |
| 网络 | AI 财务复盘（DeepSeek，可选） | 使用 AI 时需要 |

> 重新安装或覆盖安装后，系统常会撤销通知监听权限；打开 App 会检测并引导重新开启。

## 📖 使用说明

### 首次使用

1. 安装并打开应用
2. 按引导开启「通知使用权」（智能记账）
3. 按需开启悬浮窗（模糊账单确认）
4. 可在首页点「总余额」设置期初金额

### 自动记账示例

| 渠道 | 通知示例 | 说明 |
|------|----------|------|
| 微信 | `已支付¥16.00` / `[N条]微信支付：已支付¥…` | 含付款码与聚合补全 |
| 支付宝 | `你有一笔 xx 元的支出` | |
| 云闪付 / 抖音 / 京东淘宝 | 明确支付确认文案 | 营销推送会过滤 |
| 工商银行等 | `支出(消费支付宝-商户)79元` | 支持部分截断金额确认 |
| 退款 / 收入 | `收入(退款…)xx元` | 记为收入 |

金额模糊或不完整时，会弹出确认页，可改金额后选择计入或忽略。

### 智能分类（部分）

| 分类 | 示例关键词 |
|------|-----------|
| 餐饮 | 麦当劳、美团、饿了么、瑞幸… |
| 交通 | 滴滴、地铁、12306… |
| 购物 | 淘宝、京东、拼多多… |
| 娱乐 | 爱奇艺、B站、Steam… |
| 居住 / 医疗 / 教育 / 通讯 | 物业水电、医院药店、培训、运营商… |
| 其他 | 未匹配到的交易 |

可在首页长按账单修改分类，或进入分类管理自定义。

## 🆚 与上游 SmartLedger 的差异

LedgerSee 在 SmartLedger 的基础上继续演进，主要新增：

- **AI 财务复盘**：本地聚合统计后由 DeepSeek 生成月度分析（本仓库新增模块）
- **截图记账**：ML Kit 本地中文 OCR，识别账单截图后人工确认再入库（本仓库新增模块）
- **通知解析增强**：聚合摘要金额补全、银行截断金额确认、营销与退款状态过滤
- **AI 月报缓存**：新增 `ai_reports` 表，Room 数据库迁移至 v2

原始解析规则、分类体系与界面结构沿用上游实现。

## ⚠️ 已知问题与建议

1. **国产机杀后台**  
   小米 / 华为 / OPPO / vivo 等可能杀掉通知监听。请开启自启动、关闭电池优化，并在最近任务中锁定 App。

2. **重装后权限丢失**  
   属系统行为，App 会弹窗引导重新授予通知使用权。

3. **部分银行 / 新版通知格式**  
   若漏记，请用手动记账，并在反馈中附上通知全文或截图，便于补充解析规则。

4. **无云端同步**  
   数据仅存本机。AI 相关功能（月度复盘、碎碎念、和碎碎聊聊）均为可选，需您明确授权后才会把账单信息发送给 DeepSeek：复盘发送聚合统计，聊天发送本月收支与最近十笔摘要。通知原文、短信、卡号与备注一律不发送。

5. **更新需挂 APK**  
   应用内更新依赖 GitHub Release 附件中的 `.apk`；仅打 Tag 无附件时无法应用内下载。
